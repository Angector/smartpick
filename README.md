# گوشی‌یار | SmartPick

**گوشی مناسب تو، با انتخابی هوشمندانه.**

SmartPick یک وب‌اپلیکیشن **فقط فرانت‌اند** است که به کاربر کمک می‌کند بر اساس بودجه، نوع استفاده، اولویت‌ها و برند ترجیحی، مناسب‌ترین گوشی موبایل را پیدا کند.

> ⚠️ SmartPick **فروشگاه آنلاین نیست**؛ یک ابزار انتخاب و مقایسه است.

---

## ✨ ویژگی‌ها

- **پرسش‌نامه‌ی ۵ مرحله‌ای**: بودجه → نوع استفاده → اولویت‌ها → برند → مرور.
- **موتور توصیه‌ی قطعی (deterministic)**: امتیازدهی وزن‌دار روی کاتالوگ محلی، بدون AI یا API.
- **شفافیت داده**: قیمت نامشخص ≠ «در بودجه»، داده‌ی ناقص به‌صراحت علامت‌گذاری می‌شود، توصیه‌ها همیشه دلیل دارند.
- **کاتالوگ گوشی**: کارت، مودال جزئیات کامل، فیلتر برند.
- **مقایسه‌ی تا ۳ گوشی** با تاکید بصری روی بهترین امتیاز هر ردیف.
- **علاقه‌مندی‌ها و سبد مقایسه** با ذخیره‌سازی در `localStorage` (بدون حساب کاربری).
- **فارسی و RTL**، فونت Vazirmatn، اعداد فارسی و واحد تومان.
- **دسترس‌پذیر**: focus trap در مودال، aria attributes، پشتیبانی از `prefers-reduced-motion`.
